Git Repository

მოკლე და მარტივი პასუხები Git-ის შესახებ

01

Local Repository და Remote Repository

Local Repository არის Git-ის რეპოზიტორია, რომელიც შენს კომპიუტერში ინახება.

Remote Repository კი განთავსებულია დისტანციურ სერვერზე, მაგალითად GitHub-ზე.

02

რას აკეთებს git push?

git push აგზავნის ლოკალურ რეპოზიტორიაში შესრულებულ commit-ებს Remote Repository-ში.

მაგალითად:

git push origin main
03

რას ნიშნავს origin?

origin არის Remote Repository-ის სტანდარტული სახელი Git-ში.

მაგალითად, git push origin main ნიშნავს, რომ ცვლილებები გაიგზავნება origin-ის სახელით მითითებულ Remote Repository-ში.
